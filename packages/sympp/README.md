# sympp skill source

This directory owns the procedures, launcher and local runtime tests used by the
portable `skills/sympp` bundle. Run `node scripts/package-portable-skills.mjs` from
the repository root after changing packaged files.

Install with `npx skills add JJLiebig/sympp -g`, then tell your agent "set up sympp".
See [installation](../../docs/portable-skills.md) and [runtime](../../docs/runtime.md).
The `plugins/` directory only contains migration notices for retired installs.
